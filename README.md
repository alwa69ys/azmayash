# آزمایا (AZMAYA) — بک‌اند و سایت واقعی، آماده‌ی انتشار

این نسخه دیگر یک فایل نمایشیِ تنها-مرورگر نیست؛ یک **سرور واقعی Node.js** است که
سایت را سرو می‌کند، کاربران و تراکنش‌ها را روی دیسک سرور نگه می‌دارد، و به‌طور واقعی
به زرین‌پال و پارس‌گرین وصل می‌شود.

## چرا کد تأیید ارسال نشد (نسخه‌ی قبلی)؟
نسخه‌ی قبلی یک فایل HTML تکی بود که فقط در مرورگر اجرا می‌شد — هیچ سروری نداشت،
پس اساساً امکان ارسال پیامک واقعی وجود نداشت. این نسخه یک سرور واقعی دارد و
واقعاً به وب‌سرویس پیامک وصل می‌شود (به بخش «یک قدم تا کارکردن کامل پیامک» زیر نگاه کنید).

---

## ۱) نصب و اجرا (۲ دقیقه)
```bash
cd azmaya-backend
npm install
npm start
```
سایت روی `http://localhost:3000` بالا می‌آید. پنل مدیریت: `http://localhost:3000/#/admin/login`

**حساب مدیر پیش‌فرض:** `admin@azmaya.ir` / `admin123` — بلافاصله بعد از اولین ورود، از پنل مدیریت رمز را عوض کنید (فعلاً باید مستقیم در `data/seed.json` هش رمز جدید را جایگزین کنید؛ در فاز بعد یک فرم «تغییر رمز مدیر» هم اضافه می‌کنم اگر بخواهید).

---

## ۲) یک قدم تا کارکردن کامل پیامک (این را حتماً بخوانید)
کلید API که برایم فرستادید را از قبل در فایل `.env` گذاشته‌ام (`SMS_API_KEY`) — این فایل فقط
روی سرور شماست و هرگز به مرورگر فرستاده نمی‌شود، پس امن است.

اما ساختار دقیق درخواست وب‌سرویس پارس‌گرین (آدرس و نام پارامترها) را نتوانستم از مستندات عمومی
با اطمینان کامل تأیید کنم؛ چیزی که حدس بزنم و باز کار نکند به شما کمکی نمی‌کند. برای همین:

1. وارد پنل پارس‌گرین خودتان شوید → بخش «وب‌سرویس» (همان صفحه‌ای که اسکرین‌شاتش را فرستادید).
2. کنار متد ارسال پیامک (Send یا SendOTP)، یک لینک «نمونه کد» هست — نسخه‌ی **PHP یا Node/JavaScript یا cURL** آن را باز کنید.
3. فایل `lib/sms.js` را باز کنید؛ فقط تابع `sendViaParsGreen` را با همان نمونه‌کد (آدرس URL و نام پارامترها) جایگزین کنید. بقیه‌ی فایل و کل سایت دست‌نخورده کار می‌کند.
4. سرور را ری‌استارت کنید (`npm start`).

تا این تطبیق را ندهید، سایت هرگز «گیر» نمی‌کند: کد تأیید همیشه در ترمینالی که سرور
در آن اجرا شده چاپ می‌شود (خط `📩 [OTP] ...`)، پس می‌توانید همه‌چیز را تست کنید.
اگر در انجام این تطبیق کمک خواستید، همین‌جا بگویید — نمونه‌کد را برایم بفرستید تا خودم جایگزین کنم.

**شماره خط ارسال‌کننده:** مقدار `SMS_SENDER_NUMBER` در `.env` را هم از پنل پارس‌گرین (بخش امکانات/خطوط) پر کنید.

---

## ۳) فعال‌سازی پرداخت واقعی (زرین‌پال)
1. مرچنت‌کد را از پنل [zarinpal.com](https://www.zarinpal.com) بگیرید.
2. در فایل `.env`: `ZARINPAL_MERCHANT_ID=مرچنت‌کد‌شما`
3. برای تست بدون پول واقعی: `ZARINPAL_SANDBOX=true` (فعلاً همین است).
4. وقتی برای گرفتن پول واقعی آماده بودید: `ZARINPAL_SANDBOX=false` و سرور را ری‌استارت کنید.

درخواست و تأییدِ پرداخت (`lib/zarinpal.js`) طبق مستندات رسمی و پایدار زرین‌پال (REST v4) نوشته شده
و نیازی به تغییر ندارد.

## ۴) آماده‌سازی برای انتشار واقعی (Checklist)
- [ ] دامنه بخرید و روی سرورتان (VPS ایرانی یا خارجی با IP قابل دسترس از ایران) تنظیم کنید.
- [ ] گواهی SSL بگیرید (رایگان با Let's Encrypt/Certbot) — پرداخت آنلاین بدون HTTPS کار نمی‌کند.
- [ ] `PUBLIC_URL` در `.env` را به آدرس واقعی دامنه (با https) تغییر دهید — زرین‌پال برای بازگشت کاربر از همین آدرس استفاده می‌کند.
- [ ] `NODE_ENV=production` را در `.env` بگذارید.
- [ ] یک `JWT_SECRET` تصادفی و متفاوت برای نسخه‌ی نهایی بسازید (فعلاً یک مقدار تصادفی گذاشته‌ام، ولی بهتر است خودتان دوباره تولید کنید).
- [ ] پارس‌گرین را طبق بخش ۲ تطبیق دهید.
- [ ] زرین‌پال را طبق بخش ۳ با مرچنت واقعی و `ZARINPAL_SANDBOX=false` تنظیم کنید.
- [ ] رمز حساب مدیر پیش‌فرض را عوض کنید.
- [ ] سرور را با یک ابزار مدیریت پردازه مثل **PM2** اجرا کنید تا با ری‌استارت سرور یا کرش، خودش دوباره بالا بیاید:
  ```bash
  npm install -g pm2
  pm2 start server.js --name azmaya
  pm2 save
  pm2 startup
  ```
- [ ] یک **Nginx** جلوی سرور Node بگذارید (reverse proxy) تا هم SSL را مدیریت کند هم دامنه را به پورت 3000 وصل کند. نمونه‌ی کانفیگ:
  ```nginx
  server {
      listen 80;
      server_name azmaya.ir www.azmaya.ir;
      location / {
          proxy_pass http://localhost:3000;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
      }
  }
  ```
  سپس با `certbot --nginx` گواهی SSL رایگان بگیرید.
- [ ] از فایل `data/db.json` مرتب بک‌آپ بگیرید (شامل کل اطلاعات کاربران/تراکنش‌ها/نتایج است).

## ۵) چیزهایی که در همین تحویل، تست و اصلاح شد
هنگام ساخت این نسخه، با تست خودکار (Playwright + درخواست‌های واقعی HTTP) چند اشکال واقعی پیدا و برطرف شد:
- **باگ نمره‌دهی آزمون‌های تستی:** قبلاً نمره بر اساس «چند سؤال را جواب دادی» حساب می‌شد، نه «چند تا درست بود». الان نمره‌دهی کاملاً روی سرور و بر اساس پاسخ صحیح انجام می‌شود (و پاسخ صحیح هرگز به مرورگر کاربر فرستاده نمی‌شود، تا کسی نتواند با دیدن کد صفحه تقلب کند).
- **یک رِیس‌کاندیشن در ناوبری:** اگر کاربر سریع بین صفحات جابه‌جا می‌شد، گاهی صفحه‌ی قبلی (کندتر) با تأخیر روی صفحه‌ی جدید بارگذاری می‌شد و آن را بازنویسی می‌کرد. با یک مکانیزم نسخه‌بندی رندر، این مشکل کاملاً برطرف شد.
- **وابستگی به Google Fonts:** فونت وزیرمتن قبلاً از سرورهای گوگل بارگذاری می‌شد که می‌تواند برای کاربران ایرانی مشکل اتصال داشته باشد. الان فونت به‌طور کامل روی خودِ سرور شما میزبانی می‌شود و هیچ درخواستی به گوگل نمی‌رود.
- فاویکون سایت هم درست شد (قبلاً درخواست ناموفق می‌داد).

همه‌ی این‌ها با اجرای واقعی سایت در مرورگر (نه فقط خواندن کد) تست و تأیید شدند.

## ساختار پروژه
```
server.js          سرور اصلی و همه‌ی مسیرهای API
db.js              لایه‌ی داده (فایل JSON روی دیسک)
lib/sms.js         اتصال به پارس‌گرین (نقطه‌ای که باید تطبیق دهید)
lib/zarinpal.js    اتصال واقعی به زرین‌پال
lib/auth.js        نشست ورود با JWT در کوکی امن
data/seed.json     داده‌ی اولیه (اولین اجرا از این کپی می‌شود در data/db.json)
public/            کل فرانت‌اند (index.html, app.js, style.css, لوگو، فونت‌ها)
.env               تنظیمات محرمانه‌ی سرور — هرگز منتشر نکنید
```

اگر برای مرحله‌ی بعد به کمک نیاز داشتید — نمونه‌کد دقیق پارس‌گرین، گرفتن مرچنت زرین‌پال،
یا راه‌اندازی روی یک سرور/هاست مشخص — بگویید تا قدم‌به‌قدم پیش برویم.
